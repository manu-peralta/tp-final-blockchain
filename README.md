# Trabajo final: vulnerabilidades en una bóveda de ETH

## Ejecución

Requiere Node.js 20 y npm. Desde esta carpeta ejecutar los mismos comandos que los vistos en la clase para instalar dependencias y testear:

```sh
npm ci
npm test
```

Los tests de la versión vulnerable pasan cuando reproducen el fallo y los de la corregida comprueban la solución.

La descripción de la bóveda, las reglas de las pruebas, los resultados de cada caso y las referencias están en el [informe](informe/Informe.md), también disponible en [PDF](informe/Informe.pdf).
